# TraceIt Architecture

TraceIt is a multi-tenant lost property management platform.

Flow:

User
↓
Institution Selection
↓
Authentication
↓
Role-Based Access
↓
Lost / Found Module
↓
AI Matching Engine
↓
Admin Verification
↓
OTP Pickup

Roles:

Student
- Report lost items
- View status

Security
- Upload found items
- Verify pickups

Admin
- Manage institution
- Manage users
- View analytics
