# TraceIt

AI-Powered Lost Property Management Platform

## Vision

TraceIt is a multi-tenant lost property management system designed for institutions such as universities, corporate campuses, transit hubs, and public organizations.

## Core Features

- Institution-based architecture
- Role-based access control
- Lost item reporting
- Found item management
- AI-powered matching (BLIP + CLIP)
- OTP-based verification
- Admin dashboard
- Multi-campus scalability
